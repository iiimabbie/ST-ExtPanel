# SillyTavern 扩展面板管理器

通过隐藏、排序和跨列移动面板，整理 SillyTavern 的扩展程序设置页面。界面语言会跟随 SillyTavern 的语言设置。

## 功能

- 显示或隐藏受管理的面板，不会卸载对应的扩展程序。
- 拖动面板标题，在同一列调整顺序或移动到另一列。
- 确认后将显示状态、顺序和列位置保存在浏览器中，并在页面加载时应用。
- 取消编辑可恢复之前的显示状态、顺序和列位置。

> [!NOTE]
> 受管理的面板是两个设置列中具有标识符且包含内联抽屉标题的直接子元素。嵌套抽屉的显示状态随父面板变化。页面加载后最多 15 秒内，面板出现时会应用保存的顺序和显示状态。

## 安装方法

1. 在 SillyTavern 中打开**扩展程序**，点击**安装扩展程序**。
2. 输入 `https://github.com/iiimabbie/ST-ExtPanel` 并安装。
3. 确认已启用 **Extension Panel Manager**。

## 使用方法

1. 在扩展程序面板中，点击安装按钮旁的**管理面板**。
2. 使用复选框设置面板显示状态；编辑时隐藏的面板会以半透明显示。拖动标题调整面板位置。
3. 点击**保存**保存设置，或点击**取消**放弃布局更改。

进入编辑模式时会收起已展开的抽屉；取消会恢复布局，但不会恢复抽屉的展开状态。
