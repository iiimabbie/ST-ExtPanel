# SillyTavern 擴充功能面板管理器

隱藏、排序及跨欄移動面板，整理 SillyTavern 的擴充功能設定頁面。

## 功能

- 顯示或隱藏受管理的面板，不會解除安裝對應的擴充功能。
- 拖曳面板標題，在同一欄調整順序或移動至另一欄。
- 確認後將顯示狀態、順序及欄位位置儲存在瀏覽器的 `localStorage`，並於頁面載入時套用。
- 取消編輯可還原先前的顯示狀態、順序及欄位位置。

> [!NOTE]
> 受管理的面板是兩個設定欄位中包含內嵌抽屜標題的直接子元素。巢狀抽屜的顯示狀態隨父面板變動。頁面載入時，儲存的順序僅套用於當時已存在的面板；稍後載入的面板只會在最多 15 秒內檢查並套用儲存的顯示狀態。

## 安裝方式

1. 在 SillyTavern 開啟擴充功能面板，點選安裝擴充功能按鈕（英文介面為 **Install extension**）。
2. 輸入 `https://github.com/iiimabbie/ST-ExtPanel` 並安裝。
3. 確認已啟用 **Extension Panel Manager**。

## 使用方式

1. 在擴充功能面板中，點選安裝按鈕旁的 **管理面板**。
2. 使用核取方塊設定面板顯示狀態；編輯時隱藏的面板會以半透明顯示。拖曳標題調整面板位置。
3. 點選勾號按鈕（提示文字為 **確認**）儲存，或點選叉號按鈕（提示文字為 **取消**）捨棄版面變更。

進入編輯模式時會收合已展開的抽屜；取消會還原版面，但不會還原抽屜的展開狀態。
